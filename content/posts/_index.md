## What Shay has built

Shay has built two main portfolio projects:

- **Warrantour**, a deployed full-stack warranty manager. It gives users one place to create an account, register products, store receipt and warranty information, view expiry dates, and receive reminder emails. The system combines a React and Vite frontend with a Java and Javalin REST API, Hibernate, PostgreSQL, JWT authentication, SendGrid notifications, Docker, GitHub Actions, Watchtower, Caddy, and HTTPS.
- **The RAG portfolio assistant**, the custom chatbot available on this website. It answers questions from the portfolio's own pages using Dify for retrieval and orchestration, a Python content-sync pipeline, a Cloudflare Worker that protects the API key, and a custom JavaScript interface with streamed responses and linked citation dropdowns.

This portfolio itself is built with Hugo and a customized Blowfish foundation. Its interface includes responsive project pages, tag-based project discovery, section navigation, search, motion, and the integrated RAG assistant.

The AIDA collection documents Shay's practical work with retrieval-augmented generation, LLM APIs, code agents, specifications, security, ethics, Model Context Protocol, and an AI-driven team project.
